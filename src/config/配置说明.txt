============================================================
CPSS 配置文件 cpss.ini 说明
============================================================

【重要】本文件是 cpss.ini 的配套说明。
cpss.ini 位于程序运行目录（如 src/build/bin/Release/cpss.ini），
由程序（QSettings）自动读写。由于 QSettings 重写文件时会清除注释，
因此详细说明单独放在本文件中，请勿在 cpss.ini 里手写注释（会被冲掉）。

修改配置后一般需重启程序生效；回放转发的部分设置在面板打开时读取。

============================================================
[Display] 显示设置
============================================================
ColorScheme=NIGHT
    界面主题。
    DAY   = 白天（浅色主题）
    NIGHT = 黑夜（深色主题）
    切换会同时改变 Qt 界面与 Enclib 海图配色。

Use3DModel=true
    平台目标显示模式：
    true  = 3D 姿态图集（预渲染的飞机/舰船/导弹等姿态图，带俯仰/横滚）
    false = 2D 平面军标图标（原有 JB_Souce 图标）
    此开关对 chart 海图和 htmapplugin 同时生效（公共 PlatformItem）。

--- 3D 姿态图集相关（Use3DModel=true 时有效）---
AtlasDir=3dParty/models/atlases
    姿态图集目录（相对程序运行目录，找不到时自动上溯到 src 目录）。
    图集文件名格式：{模型名}_{gray|red|blue}.png
    每个图集包含 36航向 × (5俯仰×7横滚) 个姿态格子。

AtlasHeadingSteps=36
    图集的航向档数（360° / 36 = 每档10°）。
    必须与生成图集时的参数一致，否则取图错位。
AtlasRollSteps=7
    图集的横滚档数（-45°~45°，共7档，每档15°）。
AtlasPitchSteps=5
    图集的俯仰档数（-30°~30°，共5档，每档15°）。
AtlasTileSize=128
    图集中每个姿态格子的像素尺寸（生成时的 size 参数）。

ModelIconSize=64
    地图上平台图标的显示尺寸（像素）。
    图集格子原始 AtlasTileSize(128) → 缩放到此尺寸显示。
    越大越清晰，但占用更多屏幕空间；建议 48~96。

ModelBorderColor=auto
    3D 飞机模型的边框颜色（图集按边框色分 gray/red/blue 三套）：
    auto  = 按平台阵营自动选（红方→red，蓝方→blue，其他→gray）
    gray  = 全部强制灰边框
    red   = 全部强制红边框
    blue  = 全部强制蓝边框
    注意：仅边框着色，飞机主体保持图集原始灰白明暗立体感。

BoundingBoxColor=#00A8FF
    点击平台时显示的 3D 透明包围盒线框颜色（#RRGGBB 格式），默认亮蓝色高亮细线。
    无效值回退到默认亮蓝色 #00A8FF。

--- 类型到模型映射 ---
    数据源的 type（aircraft/surface/...）映射到 6 种程序化模型名。
    可用模型：fighter(三角翼战斗机) / destroyer(驱逐舰) / carrier(航母)
              drone(无人机) / recon(侦察机) / missile(导弹)
ModelAircraft=fighter
    空中目标使用的模型。
ModelSurface=destroyer
    水面舰艇使用的模型。
ModelSubmarine=carrier
    水下目标使用的模型。
ModelLand=missile
    陆地目标使用的模型。
ModelSpace=recon
    太空目标使用的模型。
ModelMissile=missile
    导弹使用的模型（AFSIM category 6~10 或 name 含 _weapon_ 识别为导弹）。

说明：
    图集由 tools/gen_models.py 生成（6种程序化模型 × 3种边框色）。
    修改模型映射只需重启程序，无需重新编译；若换成自定义图集需重新生成。

============================================================
[HtMap] HT 地图插件（WMTS 瓦片地图）
============================================================
Mode=GeoServer
    地图数据源模式：
    Local     = 本地离线瓦片（目录由 LocalRoot 指定）
    GeoServer = GeoServer GWC WMTS 服务（推荐）

LocalRoot=3dParty/mapdata
    本地瓦片根目录（Mode=Local 时有效），相对路径自动上溯到 src。

GeoServerUrl=http://localhost:8082/geoserver/gwc/service/wmts
    WMTS 服务地址（Mode=GeoServer 时有效）。

WmtsLayer=world_dom
    WMTS 图层名。
GridSet=EPSG:4326
    WMTS 瓦片矩阵集（经纬度网格）。
MaxZoom=21
    支持的最大缩放层级。
CacheSize=512
    瓦片内存缓存条目数（LRU 淘汰）。
FixedZoom=-1
    固定层级：-1 = 允许自由缩放；>=0 = 锁定该层级。
DefaultZoom=9
    程序启动时的默认缩放层级。
CenterLon=105.0
CenterLat=30.0
    地图初始中心点（经度/纬度，度）。

说明：
    GeoServer 服务可用 start_geoserver_docker.ps1 启动（Docker 容器，端口 8082）。
    瓦片为 256×256 PNG，EPSG:4326 网格（col=2^(z+1) 列, row=2^z 行）。

============================================================
[Redis] Redis 数据源（AFSIM 态势数据接入）
============================================================
Host=127.0.0.1
    Redis 服务器 IP（AFSIM redis_ext 发布端地址）
Port=6379
    Redis 服务器端口
说明：
    订阅频道固定为 target:data:channel（代码中写死，不在此配置）。
    Redis SDK 只有 Release(/MD) 版，Debug 下该适配器不启用。

============================================================
[PgDds] PGDDS 适配器（国产 DDS，nonfixed 动态类型）
============================================================
Enabled=true
    是否启用 PGDDS 适配器。
    true  = 启用
    false = 禁用
DomainId=0
    DDS Domain ID（域编号），通信双方必须一致。
BindAddress=127.0.0.1
    绑定的本机 IP，DDS 从该网卡收发数据。
    多网卡机器需设为实际网卡 IP（如 192.168.0.215）。
PlatformTopic=cpss/platform
    平台数据 Topic 名称。
EventTopic=cpss/event
    事件数据 Topic 名称。

============================================================
[ReplayForward] 历史回放-转发总设置
============================================================
Mode=0
    转发方式（单选）：
    0 = 关闭转发
    1 = DDS
    2 = UDP
    3 = TCP
Format=1
    转发数据格式：
    0 = JSON 文本
    1 = 二进制（CustomizeInfoC 结构体，265 字节）
ByteOrder=1
    二进制数据的字节序（Format=1 时有效）：
    1 = 大端（Big-Endian）
    0 = 小端（Little-Endian）
    第三方软件按 C struct 解析时必须与此设置一致。
    注意：此项由回放界面"字节序"单选框保存，请勿在 ini 里手改后期望立即生效
    （界面打开时会读取，关闭界面时会按单选框值覆盖）。

============================================================
[ReplayForward.Dds] 转发方式=DDS 时的配置
============================================================
domain=0          DDS Domain ID
bindAddress=127.0.0.1   绑定 IP
platformTopic=cpss/platform   平台数据 Topic
eventTopic=cpss/event   事件数据 Topic
说明：复用 PgDds 适配器发布，含义与 [PgDds] 相同。

============================================================
[ReplayForward.Udp] 转发方式=UDP 时的配置
============================================================
subMode=Unicast
    UDP 子模式：
    Unicast   = 单播（点对点）
    Multicast = 组播（一对多）
targetIp=127.0.0.1
    单播目标 IP（subMode=Unicast 时有效）
multicastAddr=239.255.0.1
    组播地址（subMode=Multicast 时有效）
    范围 224.0.0.0 ~ 239.255.255.255
port=12345
    目标端口（单播/组播共用）
ttl=2
    组播 TTL（subMode=Multicast 时有效）
    1    = 仅本子网
    2~16 = 有限跨网段（每经过一个路由器 +1）
localInterface=
    组播发送网卡名（subMode=Multicast 时有效）
    留空 = 系统自动选择网卡
loopback=true
    组播回环（subMode=Multicast 时有效）
    true  = 本机也能收到自己发出的数据（便于调试）
    false = 本机收不到自己发的数据

============================================================
[ReplayForward.Tcp] 转发方式=TCP 时的配置
============================================================
targetIp=127.0.0.1
    目标服务器 IP
port=12346
    目标服务器端口
reconnectMs=3000
    断线重连间隔（毫秒）

============================================================
回放数据说明（转发出去的数据）
============================================================
1. 录制文件（.cpssrec）中存储的是 AFSIM 原始数据：
   HTProto::Customize_Info 的 protobuf 序列化字节，
   每条记录前有 14 字节头（数据类型1字节+来源1字节+时间8字节+长度4字节）。

2. 回放转发（UDP/TCP）发出的数据：
   二进制模式（Format=1）= CustomizeInfoC 结构体（265字节），
   由 protobuf 解析后按 ByteOrder 指定字节序序列化。
   第三方按如下 C 结构体解析（1字节对齐，无 padding）：

   #pragma pack(push, 1)
   struct CustomizeInfoC {
       int32_t  id;                  // 平台ID
       uint32_t entityId;            // 实体ID
       uint32_t entityCamp;          // 阵营：1=蓝方, 2=红方
       uint32_t domain;              // 空间域
       uint32_t category;            // 类别
       int32_t  batchNumber;         // 批次号
       int32_t  height;              // 高度（米）
       int32_t  longitude;           // 经度 x1e6
       int32_t  latitude;            // 纬度 x1e6
       int32_t  absoluteHeading;     // 绝对航向 x1e6
       int32_t  relativeHeading;     // 相对航向 x1e6
       int32_t  threatLevel;         // 威胁等级
       int32_t  distance;            // 距离
       int32_t  azimuth;             // 方位角
       int32_t  targetSpeed;         // 速度
       int32_t  targetType1;         // 目标类型
       int32_t  enemyFriendship;     // 敌我关系
       int32_t  civilianFriendship;  // 民用关系
       char     name[128];           // 名称（UTF-8）
       uint8_t  isAlive;             // 是否存活
       char     elevation[64];       // 海拔（字符串）
   };
   #pragma pack(pop)

   注意：long 类型在 Windows 是 4 字节、Linux 64位是 8 字节，
   跨平台请使用 int32_t/uint32_t 等固定宽度类型。
