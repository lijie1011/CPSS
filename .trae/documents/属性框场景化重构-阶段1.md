# 海图属性框场景化重构 —— 阶段1

## Context（背景与目标）

海图上除平台图元（`PlatformItem`）外，还有属性框、连接线、传感/武器作用圈、航迹、事件标记等元素。当前属性框用的是 `QLabel(this)` + `Qt::FramelessWindowHint | Qt::Tool` 顶层浮动窗口，定位在**全局屏幕坐标**，不在场景里。由此带来一系列问题：

- **不统一**：其它元素都是场景内 `QGraphicsItem`，唯独属性框是独立 QWidget，坐标系、删除方式、事件处理都是另一套。
- **不跟随**：海图缩放/平移（Enclib 重绘背景）时，属性框作为独立窗口不跟随，位置要手动重算。
- **删除繁琐**：平台删除时属性框、连接线不会自动清理，需专门处理。
- **无法级联**：因为不是场景 item，无法为后续"附属元素挂到平台图元下、`delete` 平台即级联删除"（阶段2）做准备。

本阶段目标：把属性框从 QLabel 顶层窗口重构为**场景内自定义 `QGraphicsObject`（`PropertyBoxItem`）**，在**完整保留现有三项交互**（拖动、双击删除、虚线连接）的前提下，让属性框统一进入场景坐标体系、随海图缩放平移自动跟随，并满足用户确认的跟随交互：

- **默认附着**：属性框跟随平台移动（框位置 = 平台锚点 + 偏移）。
- **拖动即脱离**：用户一旦拖动过，自动切为"脱离/固定"，停在放置位置不再跟随。
- **双击删除**：双击属性框删除该框（与现状一致）。
- **平台删除必清理**：删除平台时，其属性框与连接线一并删除（靠 id 逻辑归属手动删，**不**用 `setParentItem`，以保留"脱离固定"能力）。

> 关键坐标事实（已核实）：view 关闭滚动条、`sceneRect` 与视口 1:1（`resizeEvent` 设 `setSceneRect(0,0,width(),height())`），无 QGraphicsView transform 缩放（缩放由 Enclib 背景重绘实现）。因此 **场景坐标 ≡ 视图坐标**，且 `geoToScreen(lon,lat)` 返回的就是**场景坐标**（现有 `PlatformItem::setPos` 直接用它）。重构后全程用场景坐标，彻底去除 `mapToGlobal / mapFromGlobal / QApplication::desktop()`。

阶段2（把传感/武器圈、航迹、连接线 `setParentItem` 到 `PlatformItem` 做级联删除）不在本次范围，仅在末尾预留衔接点。

## 新增：PropertyBoxItem 类

新增文件 `d:\ZCHH\CPSS\src\propertyboxitem.h` / `propertyboxitem.cpp`。遵循项目规范：中文 Doxygen 注释、`QStringLiteral`/`QString::fromLocal8Bit`、`/utf-8`（目标 cpss 已启用）。

**基类：`QGraphicsObject`**（同时是 QObject + QGraphicsItem，支持 Q_OBJECT/信号槽；`CMAKE_AUTOMOC ON` 自动处理 moc）。用信号把交互抛给 view，避免 item 反向直接调用 view，契合"信号槽通信"精神。

关键成员与接口：

- 构造：`PropertyBoxItem(const QString &id, bool isEvent, QGraphicsItem *parent=nullptr)`
- 重写：`QRectF boundingRect() const`、`void paint(...)`
- 内容/样式：`setText(const QString&)`（内部 `prepareGeometryChange()` + `update()`）、`setColors(const QColor &bg, const QColor &border)`
- 归属/跟随：`boxId()`、`isEventBox()`、`isAttached()/setAttached(bool)`、`offset()/setOffset(const QPointF&)`
- 信号：`boxMoved(PropertyBoxItem*)`（拖动中）、`boxDoubleClicked(PropertyBoxItem*)`（双击）
- 事件：`mousePressEvent/mouseMoveEvent/mouseReleaseEvent/mouseDoubleClickEvent`
- 私有：`m_id, m_isEvent, m_text, m_bgColor, m_borderColor, m_font, m_padding(=8), m_attached(=true), m_offset`

绘制：`boundingRect` 由 `QFontMetricsF` 测量多行文本 + `m_padding` 得到（局部原点 0,0 为左上角）；`paint` 先 `drawRect`（bg 填充 + 1px border 边框）再 `drawText`（黑字、左对齐、自动换行）。平台框 `白底黑框`，事件框 `#FFE4E1` 底 / `#DC143C` 框（复刻现有样式）。

拖动/双击（手动实现，不使用 `ItemIsMovable`，以便插入"脱离"与信号）：

- `mousePressEvent`（左键）：记录 `m_pressScenePos = event->scenePos()`、`m_pressItemPos = pos()`，`accept()`。
- `mouseMoveEvent`：`setPos(m_pressItemPos + (event->scenePos()-m_pressScenePos))`；`m_attached=false`；`emit boxMoved(this)`。
- `mouseReleaseEvent`：`accept()`。
- `mouseDoubleClickEvent`：`emit boxDoubleClicked(this)`。（原地双击不产生 move，不会误置脱离，天然区分拖动与双击。）

层级：属性框 `setZValue(100)`，连接线 `setZValue(50)`（高于默认 0 的平台/圈/航迹/事件标记，框压在最上，线在框下背景上）。

## 风险与边界

1. **拖动/平移冲突**（最高优先级）：必须加 `mouseGrabberItem()` 守卫（见改造点11）。
2. **双击删除生命周期**：`destroyPropertyBox` 必须用 `deleteLater()`，勿 `delete`。
3. **Z 值层级**：框 100、线 50，确保框在最上；现有 item 默认 z=0。
4. **prepareGeometryChange**：`setText/setColors` 改尺寸前必须调用，防残影/命中错位。
5. **updateSinglePlatform 回写 lon/lat**：不补则 attached 框停旧位（见改造点7）。
6. **事件框无移动宿主**：统一按"锚点=geoToScreen(box.lon,box.lat)+offset"跟随，与平台框同构；`updateSinglePlatform` 只遍历平台，不会误动事件框。
7. **拖动中文本刷新**：每帧 setText 可能致框尺寸微变、轻微抖动，阶段1可接受。
8. **拖出 sceneRect**：sceneRect 固定为视口大小，框拖出视口会被裁剪；阶段1允许拖出（不 clamp），或改用 `sceneRect()` 约束（可选）。

### 阶段2 衔接点（本次不做）
传感/武器圈、航迹、连接线将来 `setParentItem` 到 `PlatformItem` 做级联删除；属性框本次**特意不挂父项**（保留脱离固定），删除靠 `removeSinglePlatform` 按 id 手动清理，与阶段2父子级联互不冲突。阶段2 若把平台改为父子相对坐标，连接线平台端可由 `geoToScreen` 改为 `platformItem->scenePos()`，届时统一简化。

## 验证（Verification）

按工作区规则：**只改代码，不编译**。交付后由用户构建运行，验证：

1. **多目标属性框显示**：点选多个平台，各自弹出属性框（白底黑框），文本随数据实时刷新。
2. **附着跟随**：未拖动的属性框随平台移动、随海图缩放/平移一起移动，连接线实时跟随。
3. **拖动脱离**：拖动某属性框后松开，它停在放置位置；此后平台移动/海图平移时该框不再跟随（固定），连接线仍连到平台锚点。
4. **拖动不误平移海图**：拖动属性框时海图背景不发生平移（`mouseGrabberItem` 守卫生效）。
5. **双击删除**：双击某属性框，该框与其连接线消失，无崩溃、无残留。
6. **平台删除/过期清理**：`removeSinglePlatform` 触发（过期或移除）时，对应属性框与连接线一并消失，无残留。
7. **事件框**：事件框（红底）正常显示、可拖动、双击删除，随海图平移跟随其地理锚点。
